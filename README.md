> [!NOTE]
> By default, the controller uses the left knob for mouse X-axis input and the right knob for mouse Y-axis input.
>
> This program converts those mouse inputs into keyboard input.
>
> It also converts the number keys `0`–`9` into the corresponding numeric keypad keys.

> [!TIP]
> Press `F11` to toggle the input conversion on or off.
>
> The conversion is disabled by default when the program starts.

> [!WARNING]
> Mouse input is disabled while the conversion is enabled.

```sh
$ cmake --preset windows-x86_64
$ cmake --build --preset windows-x86_64
```
